# REEL CAPITAL

Private, invitation-only terminal at `thereelcapital.com` for trading US equities and long options in your own TradeStation account. MARKET orders, regular session, TradeStation SIM first.

**Status:** specification and designs. Implementation is tracked in [GitHub issues](https://github.com/OnishellT/thereelcapital/issues) by milestone.

- Product decisions: [`ONBOARDING.md`](ONBOARDING.md) (Spanish, source of truth)
- Engineering docs: [`docs/`](docs/README.md)
- Designs: [`desings/`](desings/)
- Working agreements for Claude Code: [`CLAUDE.md`](CLAUDE.md)

Stack: SvelteKit, TypeScript, Effect, Better Auth, Cloudflare Workers, D1, Durable Objects.
